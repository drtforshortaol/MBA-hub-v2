Reviewed integration baseline `e77cdd635df2112e183cc3442b26b4df5d58e206`. This change hardens engineering evidence validation; it grants no approval and changes no app, manifest, media permission or operational gate.

The digest builder previously seeded shared/media/catalog.json and shared/knowledge.json without checking them for symlinks. It also checked only each requested path's last component, allowing an app/media directory symlink to be followed. An identical-byte symlink substitution could therefore retain a previously supported inherited record. Malformed provenance/evidence containers or null rows previously could throw before the helper's digest catch. Inherited approval now requires arrays of object records, including rejection of sparse arrays, and returns false for malformed inputs. Existing duplicate, unique-origin, source-identity, reviewed-status, review-reference and exact content-hash requirements remain.
