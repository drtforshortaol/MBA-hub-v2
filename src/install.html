Install & Help

Step-by-step instructions for volunteers

Guide evaluation version. Keep MBA Hub V1 available as a backup. Install V2 once; subsequent updates normally do not require reinstallation.

The same Guide link and QR code work on iPhone, Android, Windows, and Mac. Choose your device below for instructions.

Universal installation link and QR code

Copy the address below or tap Open Guide. The QR code is an alternative for phones scanning another screen or paper.

Open Guide

The QR code and link open the same website. No QR redirect service is used.

📱 iPhone — installation
  1. Use the link above in Safari, or scan the QR code with Camera and open the result in Safari.
  2. Open it in Safari.
  3. Tap Share (square with upward arrow), then Add to Home Screen and Add. Scroll the Share menu if necessary.
  4. Open the blue Hub icon while online and wait for Ready offline. In Airplane Mode, verify the Hub and an app open.

Already viewing on this iPhone? Open the Hub directly instead of scanning.

🤖 Android — installation
  1. Use the link above in Chrome, or scan the QR code with your camera.
  2. Open the link in Chrome.
  3. From the Chrome menu (⋮), choose Install app or Add to Home screen (wording varies).
  4. Open the installed Hub while connected and wait for Ready offline. Test without a connection before relying on offline use.

The menu wording varies with Android versions. A browser bookmark is also fine.

💻 Windows PC — installation
  1. On the computer, open the Hub website in Chrome or Microsoft Edge. Use the same installation address shown above.
  2. Look for the browser's Install icon in the address bar, or choose its install-app menu option.
  3. Confirm installation and open the Hub from the Start menu or desktop.
  4. Stay online until Ready offline appears.

If installation is not offered, simply bookmark the website.

Mac — installation
  1. Open the universal Guide link in Safari.
  2. On macOS Sonoma or later, select File > Add to Dock in Safari. If unavailable, bookmark the website.
  3. Open the Hub while connected and confirm Ready offline before testing offline.
📖 Using the Hub — when and how

When: preparing for a shift, working at an exhibit, or answering visitor questions.

  1. Expand a category and choose Open App, or select Search for a subject.
  2. Use Back to return to where you were, and Return to Hub to start over.
  3. Before a shift, connect to the internet, use Check offline files on the Hub, and confirm Ready offline. Then test a needed guide without internet.
🔄 Updating — when and how

When: an update is announced or expected new information is missing.

  1. Connect to the internet and open the installed Hub. Leave it open while updates prepare.
  2. Use Check offline files and wait for Ready offline. Close and reopen the Hub if the previous version remains visible.
  3. If older content remains, try the V2 refresh page.
  4. Reopen the Hub and confirm it is ready for offline use.

Keep the existing Home Screen icon. Do not routinely delete or reinstall the app or clear website data.

🛠️ Troubleshooting — when and how

When: an image, search, link or app is not working.

  1. Confirm the internet connection and reopen the Hub.
  2. Return to the Hub and reopen the affected app.
  3. If the problem persists, use the V2 refresh page and follow its instructions.
  4. Before going offline, wait for Ready offline.

If a problem remains, report the device, affected app, and exact error or status message.

🛟 Recovery — only for persistent problems

When: the Hub will not start, updates repeatedly fail, or normal troubleshooting does not help.

  1. Connect to the internet and open the standalone V2 recovery / refresh page.
  2. Follow its instructions, then reopen the Hub.
  3. If offline setup is missing or readiness is unknown, use the Hub online and report the message, device, and app name. The refresh page cannot replace missing files if they were never prepared. Do not clear data or reinstall unless specifically instructed after troubleshooting.

Bookmark the recovery page for use when the main Hub won't load.
